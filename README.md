
# Mycardgame
A simple card game application built with C++ in cocos2d-x.
## Prerequisites
- C++ Compiler (e.g., Visual Studio 2022)
- CMake
- cocos2d-x framework
- python 2.x (for cocos command line tool)

```
mkdir build
cd .\build\
cmake .. -G "Visual Studio 2022" -A Win32
cmake --build . --config Debug
D:\Mycardgame\Mycardgame\build\bin\Mycardgame\Debug\Mycardgame.exe
```
